座位轮转助手 · Windows 免安装版
================================

【怎么启动】
1. 把整个文件夹解压到桌面、文档等**可写**位置（不要放在 C:\Program Files 或只读目录）。
2. 双击「启动座位轮转助手.bat」（或直接双击 SeatRotator.exe）。
3. 会弹出一个黑色窗口，浏览器自动打开应用；**关闭黑色窗口即停止服务**。
   如果首次运行 Windows 提示「已保护你的电脑」，点「更多信息 → 仍要运行」。

【怎么用】
- 在浏览器里把 Excel 座位表（.xlsx）拖进去，按「① 导入 → ② 核对结构 → ③ 轮转规则 → ④ 预览 → ⑤ 导出」操作。
- 导出的 Excel 保存在本文件夹的「导出结果」里。
- 默认轮换周期为每 2 周（14 天），可在导出页改成 1/2/3/4 周。
- 导出文件名会按原文件名智能递进（第五轮 → 第六轮；带日期则替换日期），组长标记会跟着学生走。

【数据与隐私】
- 完全离线：只在本机运行，不联网、不上传；学生数据只保存在本文件夹。
- 可以先把「示例座位表/示例座位表（匿名）.xlsx」拖进去试用，熟悉流程。

【常见问题】
- 浏览器没自动打开？手动打开地址：http://127.0.0.1:8765/ （如果端口被占用，黑色窗口里会显示实际地址）。
- 想换电脑使用：整个文件夹拷走即可。
- 杀毒软件误报：PyInstaller 打包的程序偶尔会被误报，可加入信任；源码在 GitHub 可查。
