这个工具会替你做什么

  • 格式零损失 在原 Excel 上原位换字：合并单元格、边框、底色、字体、行高列宽、打印设置都保留。
  • 识别容错 讲台、门窗、排号、走道、课代表区自动识别，不准的地方单击改角色即可。
  • 规则说人话 前后 / 左右 / 整组 / 全班，选完立刻生成中文描述，并校验是否丢人、重人。
  • 完全离线 只监听本机，不联网、不上传，断网也能用；关掉终端即停止服务。
小提示：讲台在表格的上方还是下方，决定了「向前 / 向后」的方向。核对结构时可以手动切换。

怎么改角色

  • 单击格子 → 在浮层里选择「座位 / 结构 / 空位 / 忽略」。
  • 结构 = 讲台、门窗、标题、排号、组标签；空位 = 写了「空」的占位；忽略 = 课代表区等非座位文字。
  • 改错了点右上角「撤销」，可连续撤销 50 步。

方向是怎么算的

讲台位置决定「向前 / 向后」：向后方 = 远离讲台。

「组内轮转」只在大组内部循环；「整组互换」让大组整体换位置；「全班整体」忽略走道，全教室一起转。
